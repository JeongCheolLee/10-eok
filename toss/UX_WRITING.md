## 2. 보이스 (한 사람이 말하는 것처럼)

- **누가:** 숫자에 밝은 친구. 아는 척 안 하고, 겁주지 않고, 결과를 담백하게 읽어준다.
- **말투:** 해요체 고정. 반말·"~습니다" 금지. 과잉 존대("~시겠어요?", "~께") 금지. "보여드려요/알려드려요" 정도는 허용.
- **태도:** 결과는 **과거형 가정**으로("샀다면 … 넘었어요"). 미래를 약속하는 서술("될 거예요", "벌 수 있어요") 금지.
- **감정:** 축하는 작게("10억을 넘었어요"), 손실은 담담하게("5,391만원 줄었어요"). 이모지·느낌표 없음(부제에 느낌표는 콘솔 규정으로도 금지).

## 3. 규칙

1. **잡초 뽑기.** "가정하고", "실제로", "앞으로", "현재", "총", "~에 대한"은 빼고 읽어본다. 뜻이 같으면 뺀다.
2. **한 문장 한 메시지.** 조건·기간·결과를 한 문장에 다 넣지 말고 lead/num/sub 세 줄로 나눈다.
3. **CTA는 "~하기", 12자 이내, 다음 화면을 예고.** "10억까지 계산하기", "계산 저장하기", "다시 시도하기". 설명 문장을 반복하는 버튼("저장" 아래 "저장하기") 금지.
4. **두 버튼은 [닫기 | 행동].** "취소"는 쓰지 않는다. 광고 모달도 [닫기 | 분석 열기].
5. **숫자가 영웅.** 숫자 앞뒤 단어를 줄인다. "11년 2개월"(약 ✕), "10.19억", "100만원", "+31%". 변화량은 부호와 단위: "−5,391만원", "−5.0%".
6. **단위·날짜:** 만원·억 단위 붙여 쓰기("100만원"), 날짜는 "10월 16일 종가", 연월은 "2015년 8월". 영문 티커는 그대로(QLD), 한글 이름은 부제로("나스닥100 2배").
7. **전문용어는 표면에서 빼고 ⓘ에 넣는다.** 아래 용어 사전. 단, **위험을 설명하는 말은 순화하지 않는다**(양도세, 손실, 미달).
8. **에러는 길 안내.** "데이터를 불러오지 못했어요 / 잠시 후 다시 시도해 주세요 / [다시 시도하기]". 사과·원인 추측 없음.
9. **빈 상태는 다음 행동을 말한다.** "아직 저장한 계산이 없어요 — 계산 결과에서 '…저장하기'를 누르면 매일 아침 여기서 볼 수 있어요."
10. **면책은 매 화면 하단, 같은 문장.** "과거 자료로 계산한 결과예요. 특정 종목을 추천하거나 미래 수익을 보장하지 않아요."
11. **추천으로 읽힐 말 금지.** "추천", "유망", "지금 사면", "놓치지 마세요", "~하세요"(명령). 비교 화면 제목은 사실 서술형("같은 기간, 다른 ETF였다면?").
12. **괄호 설명 금지.** "(없으면 0)" → 칩 "없어요". "(모의)" → "미리보기".

## 계산 화면 변경 기준 (2026-10-22)

- 홈 제목은 매달 **월급날마다 ETF를 모았다면**, 매주 **매주 ETF를 모았다면**, 매일 **거래일마다 ETF를 모았다면**으로 맞춘다. 결과는 기간이므로 질문은 **10억까지 얼마나 걸렸을까요?**다. ‘그동안’으로 개인의 실제 투자 기간을 암시하지 않는다.
- 매달 사는 날은 사용자가 정한다. 월급날은 일상적인 예시이며 날짜를 자동으로 알아내거나 급여·계좌를 연결하지 않는다.
- 기본 기간 모드는 10억을 넘긴 경우 중 가장 늦게 시작한 달을 찾고, 도달한 경우가 없으면 거래 자료가 있는 처음부터 계산한다. 이 규칙은 결과의 ‘계산 기준 보기’ 안에서 안내하고 홈에서는 생략한다. **시작한 날을 정할게요**를 켜면 입력한 날부터 정액 매수를 가정한다.
- 상단 계산 모드 탭은 임시로 숨긴다. 금액 모드 저장·공유 조건은 유지하고, 해당 입력 화면에 **기간 계산으로 바꾸기**를 제공한다.
- 앱 실행 중 새 조건 계산은 처음 2회 무료다. 세 번째 새 조건부터 ‘광고 보고 계산하기’를 누르고 보상형 광고를 끝까지 보면 앱을 닫기 전까지 재계산을 해제한다. 성공한 서로 다른 조건만 세며 같은 조건 다시 보기·저장/공유 결과·입력 수정은 차감하지 않는다. 로드 오류는 이번 계산만 무료로 열고 전체 해제는 보상 이벤트에서만 한다.
- 기본 계산·저장·공유 결과는 실제 거래 이력만 사용한다. ETF 비교에 한해 기존 번들의 근거 있는 상장 전 추정 구간을 허용하며, 실제 결과와 별도 목록으로 보여준다. 추정 포함 배지·사용 자료·적용 기간·한계를 표시하고, 자료가 비교 기간 전체를 채우지 못하면 금액을 표시하지 않는다. 종목 선택에는 계산 가능한 시작월을 표시한다.
- 결과의 **계산 기준 보기**에는 기간·시작일 선택 방식·매수 일정과 금액·처음 넣은 돈·배당·세금과 수수료·가격과 환율 기준일을 보여준다.
- 도달 결과 상단은 **ETF·매회 금액 → 처음 10억을 넘기까지 걸린 기간 → 시작월·첫 도달일** 순서로 읽히게 한다. 기간을 가장 크게, **이후에도 계속 모았다면**의 평가액·기준일은 보조 카드로 보여준다. 평가액 변화 그래프와 통계 다음에 초록색 전체 너비 ‘결과 공유하기’ 버튼을 두고 금액 변경·저장은 그 아래 나란히 둔다. 시작월 선택 방식과 최단 기간을 뜻하지 않는다는 안내는 ‘계산 기준 보기’ 안에 둔다. ‘계산 기준 보기’는 ETF 비교 링크·계산 옵션 다음, 하단 광고와 면책 문구 앞에 둔다.
- **저장한 계산**은 조건별 목록이다. ETF·금액·주기·목돈·배당 조건을 보여주고 항목을 누르면 기존 결과 화면의 기간·평가액·그래프를 본다. 다른 조건은 추가하고 같은 조건은 갱신한다. 편집에서 항목별로 삭제하며, 기존 단일 저장본과 저장 키·딥링크는 호환한다. 결과는 저장된 조건으로 최신 자료를 사용해 다시 계산한다.
- 결과 화면의 **금액 바꿔 비교하기** 표는 사용자 요청으로 제거했다. **조건 바꿔보기**로 입력 화면에 돌아가 ETF·금액·주기·목돈을 바꾼다. 기존 동일 기간 비교 로직은 보존한다.
- **시작 시점 비교하기** 영역과 그 보상형 광고는 사용자 요청으로 제거했다. 계산 광고와 하단 배너를 유지한다.

## 7. 화면 위계와 비교 기준 (2026-10-22)

- 사용자가 ‘생각보다 짧네’라고 느낄 수 있도록 납입액과 과거 도달 기간을 연결해 보여준다. 결과의 기간 숫자만 진한 초록색으로 강조하고 ‘년·개월’은 작고 가벼운 회색으로 둔다. 납입액은 굵은 진회색으로 구분하며 배경 발광 효과는 쓰지 않는다. ‘금방’, ‘누구나’, ‘할 수 있어요’처럼 결과를 평가하거나 미래를 약속하는 카피는 넣지 않는다.
- 입력은 ETF·주기·금액 다음에 목돈 선택과 매수일을 둔다. 목돈은 ‘시작할 때 넣을 목돈이 있나요?’ → ‘아니요 / 네’로 고른다. 기본 입력의 시작일 직접 지정 진입은 임시로 숨기고, 기존 저장·공유 조건에서만 수정 경로를 유지한다. ‘과거 계산의 시작일에 이 금액을 한 번에 넣었다고 봐요’와 ‘처음 넣을 금액’로 시점을 설명한다. 주기를 왕복해도 입력 금액을 잃지 않게 한다.
- ETF 비교는 **같은 기간, 다른 ETF였다면?**이다. 원래 계산의 시작 일정·종료일·실제 계산 납입액을 유지한다. 기본은 ‘평가액 높은 순’이며 ‘평가액 낮은 순 / 유형별’로 전환할 수 있다. 금액순에서는 비교 불가 항목을 마지막에 분리하고 레버리지 위험 안내를 각 행에 유지한다. 순위 번호·메달·우승 표현은 쓰지 않는다. 실제 자료와 추정 포함 결과는 별도 목록에서 각각 정렬한다. 추정 자료로도 기간 전체를 채우지 못하면 금액을 표시하지 않는다.
- 금액 비교 입력칸·표는 결과 화면에 표시하지 않는다. ETF 비교 진입과 입력 조건 변경은 유지한다.
- 시작일 이후 자료가 없으면 ‘이 날짜로 계산할 자료가 없어요’와 수정 행동을 보여준다. 0원 결과·임의의 시작연도·저장 버튼으로 대체하지 않는다.
- §5의 전·후 표는 과거 변경 이력이다. 현재 화면과 다른 항목은 §6·§7 및 용어 사전이 우선한다.


## 8. 제목·종목 선택·하단 입력 후속 정리 (2026-10-23)

- 제목에서 ‘10억’은 큰 초록색 숫자로 강조하고 ‘까지,’는 작고 가벼운 회색으로 둔다. 홈 제목 아래 가격·환율 설명은 생략한다. 매수 당시 가격·환율 및 환율 누락일의 직전 값 사용은 결과의 계산 기준에서 설명한다.
- ETF 카테고리 안에서는 대표 종목이 먼저 보이도록 고정 순서를 쓴다. 이는 측정된 인지도 순위나 성과순 정렬이 아니다. 선택·검색 화면과 비교 화면의 유형별 정렬은 `TOSS_DISPLAY_TICKERS`를 함께 쓰고, 유형별 보기의 레버리지 카테고리는 마지막에 유지한다.
- 종목 선택에서 ‘○○년부터 계산할 수 있어요’와 이력 길이 안내는 제거한다. 데이터 로더의 실제 거래 기간 필터와 결과의 계산 기준은 유지한다.
- 기본 홈에는 시작일 설정을 표시하지 않는다. 홈의 자동 시작월 안내는 생략하고, 결과에서 계산 기준을 안내한다. 기존에 시작일을 지정한 저장·공유 링크에서는 날짜를 볼 수 있고 수정할 수 있어야 한다.

- 첫 입력에는 기본 종목을 미리 넣지 않는다. ‘어떤 ETF가 궁금하세요?’ → ‘ETF 선택하기’로 사용자가 선택하게 한다. 선택 창은 자동으로 열지 않는다. 선택 전에는 계산 버튼 비활성화, 선택 후에만 종목 행과 ‘ETF 추가하기’를 보여준다. 기존 저장·공유 조건은 유지한다.

- 입력 안내에 ‘~했다고 볼까요?’를 반복하지 않는다. ETF는 ‘어떤 ETF가 궁금하세요?’, 반복 매수는 ‘모으는 주기와 금액’, 목돈은 ‘시작할 때 넣을 목돈이 있나요?’와 ‘처음 넣을 금액’으로 안내한다. 과거 시점의 의미는 제목·목돈 보조 설명·계산 기준에서 전달한다.


### 입력·광고 안내 보완 (2026-10-24)
- 금액·기간 입력이 비었거나 숫자가 아니면 이전 확정값으로 계산하지 않는다. 오류 안내와 계산 비활성화를 함께 제공하고, 프리셋·증감 버튼으로 입력을 복구할 수 있게 한다.
- 보상 광고 완료 후에도 배너는 유지한다. ‘광고 없이 계산’ 대신 ‘앱을 닫기 전까지 추가 광고 시청 없이 계산해요.’로 안내한다.
- ETF 선택창은 검색 키보드를 자동으로 열지 않는다. 포커스는 선택창 안에서 유지하고 닫으면 선택 버튼으로 돌린다.
- 저장 삭제의 ‘되돌리기’는 사용자 요청으로 추가하지 않는다. 기존 편집→항목 삭제 동작을 유지한다.
