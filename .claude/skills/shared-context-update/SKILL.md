# SHARED_CONTEXT.md 갱신 (10-eok)

`~/Documents/develop/10-eok-private/SHARED_CONTEXT.md`는 Claude Code와 Codex가 같이 읽고 같이 쓰는 유일한 공용 메모다.
코드 저장소는 공개라 이 파일은 저장소 밖 비공개 폴더(로컬 git)에 있다. 자동으로 채워지지 않으므로, 이 스킬이 호출된
시점까지의 대화를 돌아보고 **직접 판단해서** 적는다.

## 1. 추릴 기준

적는다:
- 다시 겪으면 똑같이 시간 낭비할 비자명한 사실(명령 하나로 해결 안 되는 함정, 숨은 전제, 틀렸던 가정)
- 이번 세션에서 사용자가 교정한 작업 방식·판단 기준(다음에도 적용돼야 하는 것)
- 기존 항목이 이제 틀렸거나 바뀐 경우(지우거나 고친다 — 추가하지 않는다)

적지 않는다:
- 코드만 봐도 알 수 있는 것
- 이번 작업의 완료 판정·범위처럼 일회성인 것(그건 `TOSS_MASTERPLAN.md`·비공개 `CLAUDE.md` 현재 상태 블록의 몫)
- 이미 리포 `CLAUDE.md`(라이팅 규칙)나 비공개 문서에 있는 내용 그대로 반복
- 비밀번호·키·사업자번호·주소 같은 개인정보

애매하면 사용자에게 "이번 세션에서 적을 만한 게 N개 보이는데, 이것들 맞아?" 식으로 짧게 확인받는다.

## 2. 절차

1. `SHARED_CONTEXT.md`를 읽어 중복·고칠 항목을 먼저 확인한다.
2. §1 기준에 맞는 항목을 추린다.
3. 기술 메모는 "기술 메모", 그 밖의 기록은 "작업 로그" 섹션 끝에 아래 형식으로 추가한다(작성자 = Claude). 기존 항목을 고칠 땐 그 항목 자체를 수정한다.
   ```
   ## [YYYY-MM-DD] (작성자: Claude) 한 줄 제목
   무엇을·왜·어떻게 적용하는지 2~3줄.
   ```
   날짜는 오늘(`date +%F`).
4. 비공개 폴더에서 커밋한다: `git -C ~/Documents/develop/10-eok-private add SHARED_CONTEXT.md && git -C ~/Documents/develop/10-eok-private commit -m "shared-context: …"`.
5. 추가·수정한 항목만 사용자에게 짧게 보여준다.

## 3. 주의

- Codex도 그대로 읽으므로 Claude 세션 운영에만 해당하는 이야기(서브에이전트 설정 등)는 넣지 않는다.
- 한국어로 적는다. 중복은 합치고 오래된 쪽을 지운다.
