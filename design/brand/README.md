# 10억 아이콘

2026-11-09 확정한 1번 시안: 초록 배경에 굵은 흰색 `10억`.
원본은 `icon-10eok-source.png`이며, 이미지 생성 도구로 만든 승인 시안을 그대로 사용한다.

`node scripts/build-brand-assets.mjs`로 크기별 PNG와 독립 SVG를 내보낸다.
SVG 안에 PNG를 포함해 외부 이미지 요청이나 한글 폰트에 의존하지 않는다.

- 웹과 미니앱 로고: 256px PNG
- 웹과 미니앱 파비콘: 모서리 마스크를 적용한 SVG
- 토스 콘솔: `toss/store/logo-600.png`, 600px 정사각형 불투명 PNG

토스 목록과 상단 바의 로고는 콘솔 등록 이미지다. 소스 변경이나 번들 업로드만으로 교체되지 않는다.
